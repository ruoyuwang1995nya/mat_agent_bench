## Paper / Project Notes

Paper describes a high-throughput band-gap database for 10,481 semiconducting inorganic materials computed with HSE06 hybrid functional. Key workflows: (1) PBE structural relaxation → one-shot HSE06 band gap calculation, (2) magnetic ordering determination via Ising model + genetic algorithm, (3) SOC inclusion criteria for Tl/Pb/Bi compounds with Eg<1eV, (4) filtering metals for possible gap opening using DF/DVB threshold.
